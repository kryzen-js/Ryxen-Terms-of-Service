​Your privacy and the security of data handled by Ryxen are critical to us. This section outlines the principles governing how data is handled. For a full breakdown, please refer to our full Privacy Policy on GitHub.

​In order to execute commands, save server configurations, and maintain state, Ryxen collects minimal necessary metadata from Discord:
​Identifiers: Numerical Discord User IDs, Server (Guild) IDs, Role IDs, and Channel IDs.
​Configuration Settings: Custom prefixes, designated audit log channels, welcome message templates, role assignment rules, and auto-moderation threshold settings.
